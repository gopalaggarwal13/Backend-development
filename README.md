# ⚙️ Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/gopalaggarwal13/backend-development.git
```

```bash
cd backend-development
```

---

## 🌐 Run HTML Lab

```bash
cd LAB/EXP-1
start index.html
```

*(Windows)*

---

## 🚀 Run Node.js Projects

```bash
cd Theory

npm install

node server.js
```

---

## 🐍 Run Python Projects

```bash
cd Theory

python -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt
```
