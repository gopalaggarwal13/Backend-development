II

A considered layout

Responsive by design

The page begins with room for a two-column desktop layout. As the viewport narrows, the content stacks, cards reduce to fewer columns and type scales down. Nothing depends on a framework or JavaScript.

  • Fluid spacing and readable type
  • Flexible columns and card layouts
  • Navigation that wraps on narrow screens
  • Visible keyboard focus and reduced motion
