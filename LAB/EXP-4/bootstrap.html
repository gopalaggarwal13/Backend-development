Core concepts

What Bootstrap provides

Reusable building blocks for the same responsive assessment page.

01

Grid

Container, row and column classes create a responsive page structure.

02

Components

Navbar, buttons and cards provide reusable interface patterns.

03

Utilities

Spacing, display and typography classes help compose the page quickly.

04

Breakpoints

Responsive classes change columns and navigation at framework breakpoints.

The approach

Structured and component-driven

Bootstrap follows a convention-based approach. Its predefined grid and components provide a consistent starting point for responsive pages, while utility classes cover common spacing, alignment and typography tasks.

  • ✓ Responsive grid system
  • ✓ Prebuilt interface components
  • ✓ Utility classes for common styles
  • ✓ Framework breakpoint classes
Bootstrap markup

  <div class="col-md-6 col-lg-3">

  </div>
</div>

Assessment observation

Bootstrap's grid and components make common page patterns quick to assemble. Its conventions promote consistency, while custom visual details may call for theme variables or additional CSS.
