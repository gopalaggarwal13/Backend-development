Core concepts

What Tailwind provides

Small utility classes combine to create a responsive interface.

01

Utilities

Composable classes control spacing, colors, typography and display.

02

Responsive variants

Prefixes such as sm:, md: and lg: apply styles at breakpoints.

03

Flex and Grid

Layout utilities compose responsive structures directly in markup.

04

Customization

Utility combinations provide detailed control over the page's appearance.

The approach

Utility-first and flexible

Tailwind uses composable classes instead of predefined visual components. Responsive variants let the same content rearrange as the viewport changes.

  • ✓ Utility-first styling
  • ✓ Responsive variants
  • ✓ Flexbox and Grid utilities
  • ✓ Fine-grained visual control
Tailwind markup
<div class="grid gap-4
sm:grid-cols-2
lg:grid-cols-4">
  <article class="border p-5">
    Responsive feature
  </article>
</div>

Assessment observation

Tailwind's utilities make custom details explicit at the element level. This offers precise control, while long utility lists can make markup denser and benefit from reusable patterns.
