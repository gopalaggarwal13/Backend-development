I

Application methods

Three types of CSS

The same language can be applied directly to an element, inside the document head, or from a separate stylesheet. This page deliberately uses all three approaches.

01

Inline CSS

This sentence is styled with an inline style attribute. 

<p style="color: var(--rust-deep);">

Best for a very specific one-off style; difficult to maintain at scale.

02

Internal CSS

This card receives its special treatment from a <style> block.

<style>
.internal-demo { ... }
</style>

Useful when styles belong to one HTML document.

03

External CSS

This card and almost the entire page are styled through style.css.

<link rel="stylesheet"
      href="style.css">

Best for reusable, maintainable styles across multiple pages.

II

Targeting elements

Selectors

Selectors identify which HTML elements receive a CSS rule. The examples below show element, class, ID, universal, grouping, descendant and pseudo-class selectors.

element

Element selector

Targets every element of a given type.

p { line-height: 1.75; }
.class

Class selector

This card uses the reusable .class-selector class.

.card { padding: 1.25rem; }
#id

ID selector

This card is uniquely styled using an ID selector.

#id-selector-demo { ... }
h1, h2, h3

Grouping selector

One declaration can target several selectors at once.

h1, h2, h3 { ... }
.card p

Descendant selector

The paragraph is inside a card, so the descendant rule can target it.

.card p { ... }
:hover

State selector

Hover over this card to see the :hover rule.

.hover-selector:hover { ... }
III

Space around every element

CSS box model

Every normal element can be understood as a rectangular box containing content, surrounded by padding, border and margin.

MARGIN
BORDER
PADDING
CONTENT
Content
The actual text, image or child content.
Padding
Space between content and the border.
Border
The visible edge surrounding the padding.
Margin
Outer space separating the element from neighbours.
.box {
  width: 180px;
  padding: 24px;
  border: 5px solid;
  margin: 24px;
}

VI

The cascade

Specificity & inheritance

Specificity

This sentence demonstrates selector priority.

p { ... }
.specificity-target { ... }
#specificity-target { ... }

An ID selector is more specific than a class selector, which is more specific than an element selector.

Inheritance

Text properties such as font-family and color can inherit from a parent unless a child rule overrides them.

This child inherits the section's font and colour.

VIII

Experiment record

Result & observation

The web page successfully demonstrates inline, internal and external CSS along with selectors, the box model, Flexbox, Grid, responsive media queries, specificity, inheritance, transitions and keyframe animation.

  • External CSS controls the main visual system.
  • Inline and internal CSS are intentionally included as visible demonstrations.
  • Flexbox and Grid provide different layout strategies.
  • Media queries adapt the interface to smaller screens.
  • Transitions and animations provide visual feedback and motion.
