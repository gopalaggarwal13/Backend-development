ISemantic structure

Sectioning & semantic elements

HTML5 replaced the endless <div id="header"> soup of HTML4 with elements that name their own role. This document is built from them: a <header> at the top, a <nav> for the section list, this <main> region, nine <section>s, an <aside> below, and a <footer> at the end.

An <article> is self-contained

An <article> should still make sense if you cut it out and paste it somewhere else — a blog post, a product card, a forum reply. A <section> is a thematic chunk of something, so it usually does not survive that test.

Nested footers are legal — this one belongs to the article, not the page.

Aside

<aside> holds content that is tangentially related to what surrounds it: pull quotes, glossaries, related links, ad slots.

The six heading levels

Rule: exactly one <h1> per page, and never skip a level. Screen-reader users navigate by heading, so the outline is the map.

IVTabular data

Tables

HTML4 structural patterns vs. their HTML5 replacements
Purpose HTML4 approach HTML5 element
Page banner <div id="header"> <header>
Primary links <div id="nav"> <nav>
Main content <div id="content"> <main>, <section>, <article>
Media playback Flash / Silverlight plug-in → replaced entirely by <audio> and <video>
Drawing surface Java applet, <object> <canvas>, inline <svg>
Form input Text field + JavaScript validation type="email", type="date", required
Custom autocomplete widget <datalist>
Net effect: fewer wrapper divs, less JavaScript, more meaning available to machines.

VIIIInteractive elements

Disclosure & dialog

Why did HTML5 add <details>?

Accordions used to need a div, a click handler and a chunk of JavaScript. HTML5 ships the open/close behaviour natively, keyboard-accessible and announced correctly by screen readers, for free.

What is a <template>?

Markup that is parsed but not rendered until JavaScript clones it. Use it for repeated UI you will stamp out dynamically — table rows, cards, list items. Open DevTools and you will find the template below sitting inert in the DOM.

Native modal

<dialog>

Opened with showModal(). The browser handles the backdrop, focus trapping and the Esc key — behaviour that used to require a whole modal library.
